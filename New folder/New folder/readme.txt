SITE ROMÂNĂ — VERSIUNEA 1

1. Deschide index.html într-un browser.
2. Site-ul funcționează fără server și fără instalare.
3. Răspunsurile și progresul sunt salvate local în browser (localStorage).
4. Pentru modificarea întrebărilor, deschide script.js și editează lista chapters.
